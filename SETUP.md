# Sailesh Chikkam — Futuristic GitHub Profile

## Files

- `README.md` — profile layout
- `assets/hero-fluid.gif` — animated fluid hero
- `assets/matrix-rain.gif` — animated matrix section
- `assets/footer.svg` — animated footer

## Install

1. Open your profile repository:
   `saileshchikkam/saileshchikkam`
2. Replace the existing `README.md` with this `README.md`.
3. Create an `assets` folder.
4. Upload all three files from `assets/`.
5. Commit and refresh your profile.

The design uses a void-black / ice-cyan / ultraviolet / acid-lime palette and deliberately keeps the textual content minimal.
